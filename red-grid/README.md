# Red Grid

A defense-network terminal look for the Claude desktop and mobile apps. It's a dark void with red phosphor text, a faint targeting grid, CRT scanlines, a red vignette and one slow sweep band rolling down the glass. Messages get hard 2pt corners and mono type, and your own lines carry a soft red glow. Turn on the theme's sound from the speaker in the title bar for a low mains hum and short terminal blips. It's dark only. The terminal and editors don't draw themes, so it shows nothing there.
